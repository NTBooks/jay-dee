# Music Taste Profile

Written with the `jaydee-taste` interview. Every rule below should come from a real example; the DJ reads this whole file before every set.

## Critical caveats (read first)
- Is the digital library the whole collection, or a time window of it? (e.g. "pre-2000 favourites live on vinyl; never infer dislike from absence.")
- One sentence on how recommendations tend to fail for this listener.

## Core sensibility
Two or three paragraphs: what they listen for (craft, wit, texture, riffs, voices), the deep lanes in the library, and the baseline sound that runs under everything.

## Relationship tiers
- **Load-bearing favorites:** artists the station can always lean on, and why.
- **Cyclical / newcomer / arm's-length:** artists with a different activation pattern.

## Confirmed data points
Specific facts worth remembering: favourite songs, playlists that define a mood, artists whose library presence is misleading.

## Vetoes (do not re-recommend)
Names with the reason. Mirror these in `data/taste/vetoes.json`.

## How to apply
How the DJ should choose and talk: e.g. "build confidently from the library; recommend sparingly; run every pick through fresh -> earnest -> clean -> committed vocals; never water a one-track seed; keep talk short."
